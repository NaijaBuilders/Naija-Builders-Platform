# NaijaBuilders Platform

This repository hosts the NaijaBuilders Laravel application.

## Structure

- laravel-app/ : the Laravel 12 application
- .gitignore   : root ignores for legacy backup and local tooling

## Quick Start

1) cd laravel-app
2) composer install
3) copy .env.example .env
4) php artisan key:generate
5) php artisan migrate
6) npm install
7) npm run build

See laravel-app/README.md for full setup and cPanel deployment steps.
